# Reconciled annual account and conditional effects on other residents

**Verdict:** National current accounts close exactly. The declared long-run
response grid gives an annual outside-resident loss of $262.05–356.84bn after
modeled production benefits. This is a conditional model range, not a confidence
interval, historical immigration effect, admission estimate or removal saving.
See the [calculation record](../../../research/immigration-complete-annual-account-2026-09-20.md).

Read [DESIGN.md](DESIGN.md) for assumptions fixed before joining the results.
The population is40.896574m observed Mexican-origin CPS residents across all ages
and education. The comparison uses340.110988m total residents, with outside-CPS
people included in the complement and never silently added to the target.

## Reproduce

First run the three sibling modules' builders with the canonical checkout as
`--source-root`, following their READMEs:

- `full_account_receipts_2026_09_20`: complete conditional receipts and diagnostic.
- `full_account_spending_2026_09_20`: consumption, transfers, interest and subsidies.
- `full_account_benefits_2026_09_20`: freshly replayed CES and ownership scenarios.

Then, from the repository root:

```sh
UV_CACHE_DIR=/private/tmp/immigration-uv-cache uv run --offline --no-project \
  --with pandas --with numpy python3 infra/immigration-fiscal/full_account_2026_09_20/builder.py
UV_CACHE_DIR=/private/tmp/immigration-uv-cache uv run --offline --no-project \
  --with pandas --with numpy python3 infra/immigration-fiscal/full_account_2026_09_20/welfare.py
UV_CACHE_DIR=/private/tmp/immigration-uv-cache uv run --offline --no-project \
  --with pandas --with numpy python3 infra/immigration-fiscal/full_account_2026_09_20/report.py
UV_CACHE_DIR=/private/tmp/immigration-uv-cache uv run --offline --no-project \
  --with pandas --with numpy python3 -m unittest discover -s infra/immigration-fiscal/full_account_2026_09_20 -v
```

Builders verify producer output hashes and declared source dependencies before
joining. `builder.py` and `welfare.py` support `--source-root` and `--out`.
`report.py` reads this module's default `derived/`. Outputs are ignored/rederivable.

## Outputs and boundaries

`accounts.csv` contains110 cross-account cases,80 complete. Each conserves the
official national balance of−$2,053.168bn. Unknown residuals are distinct from
foreign flows. Completeness uses absolute unknown dollars so signed residuals
cannot hide one another. The normalized comparison uses only target+other domestic
assignments; it is never added to welfare. Report the per-capita-F version when
comparing contributions: the F-fixed arm deliberately exempts the target and
assigns its old share to others, changing that comparison by construction.

`response_pools.csv` lists32 conditional fiscal pools. Direct receipts exclude
corporate capital **and labor incidence**, every property-tax category,
other-business receipts and public assets. Household benefits respond fully;
business subsidies and legacy interest are held fixed. Ordinary services
respond0/.5/1; private capital adjustment is paired0/.5/1 as a declared capacity
path. Their independently varied relationship is also visible through the
continuous service-cost break-even at each CES setting. Defense/general-public
service response0/1 is separate.

`welfare_scenarios.csv` contains497,664 conditional rows. Core ownership assigns
all capital to other US residents. Excluded-owner shares.5/1 and fiscal-dollar
weights0/1 are unestimated endpoints. O=0 is the favorable overlap case within
this formula; additional overlapping receipts O≥0 only lower welfare at beta>0.
Removing all personal income tax is exported as a separate sensitivity, not a
bound on all overlap. The additional unmodeled benefit needed to reach zero is
reported; no crime, amenity or price-surplus add-on is invented. Business subsidies
to included owners would need a matching private receipt if their response changed.

`welfare_summary.csv`, `headline_cases.csv` and `headline_summary.json` provide
small views. `audit.json` and `welfare_audit.json` fingerprint the joined evidence.
The final two views are generated by `report.py`, which verifies those receipts.

Seven semantic tests cover conservation, signed unknowns, the matching population,
source drift, duplicated corporate/property receipts, subsidy separation, tax and
transfer cancellation, and welfare break-even direction. Independent native review
checked the real category mapping and62,208 selected welfare rows. The three source
modules have20 additional tests. Scenario extrema do not combine all measurement,
coverage, ownership and model uncertainty into an empirical interval.
